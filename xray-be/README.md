# X-Ray Backend (Django API & Analytics Engine)

Серверная часть и аналитический движок сервиса **AI Business X-Ray**.  
Построена на **Python 3.10+**, **Django 5.2**, **Django REST Framework** и внешней OpenAI-совместимой модели **gemini-3.8-flash-high**.

---

## Архитектура аналитического ядра (`engine/`)

- **`parsers.py`**: Парсер файлов Excel (`.xlsx`, `.xls`) и CSV. Определяет кодировки (`utf-8-sig`, `utf-8`, `cp1251`), разделители (`;`, `,`, `\t`) и извлекает сырые строки.
- **`mapping.py`**: Детерминированное распознавание колонок по синонимам и типам данных (числа, даты, деньги, проценты).
- **`ai_mapper.py`**: Fallback AI-нормализатор. Если ключевые колонки не сопоставлены по словарю, отправляет имена колонок и примеры строк в LLM для автоматического маппинга сленговых названий.
- **`normalizer.py`**: Приведение сырых строк к канонической структуре `Deal`, генерация SHA-256 идентификаторов при отсутствии `deal_id`, отсев поврежденных строк.
- **`analyzer.py`**: Расчет 7 бизнес-метрик по строгим формулам, определение уровней угрозы (`critical`, `watch`, `ok`) на основе порогов из `thresholds.yaml` и вычисление финансового ущерба (`money_impact`) в рублях.
- **`narrator.py`**: Переписывание главного вывода (`headline`) и рекомендаций (`action`) через нейросеть живым языком предпринимателя без искажения цифр.
- **`tools.py`**: Реализация инструментов для AI-чата (`search_deals`, `get_manager_stats`, `get_top_clients`).
- **`reports.py`**: Генерация фирменных отчетов в PDF (`reportlab`) и Excel (`openpyxl`).
- **`llm_logger.py`**: Запись всех входящих промптов и исходящих ответов нейросети в консоль и файл `logs/llm_debug.log`.

## Установка и запуск

```powershell
# 1. Перейдите в папку xray-be
cd xray-be

# 2. Активируйте виртуальное окружение
.\venv\Scripts\Activate.ps1
# (или source venv/bin/activate на Linux/macOS)

# 3. Установите зависимости (если необходимо)
pip install -r requirements.txt

# 4. Примените миграции базы данных
python xray_be\manage.py migrate

# 5. Запустите сервер разработки
python xray_be\manage.py runserver 127.0.0.1:8000
```

## Основные API-эндпоинты

| Метод | Эндпоинт | Описание |
| :--- | :--- | :--- |
| `POST` | `/api/uploads` | Загрузка файла, автоопределение колонок и AI-маппинг |
| `PUT` | `/api/uploads/<id>/mapping` | Сохранение подтвержденного маппинга колонок |
| `POST` | `/api/snapshots` | Запуск расчета снимка рентгена и сохранение в БД |
| `GET` | `/api/snapshots` | Список сохраненных снимков для истории на главной |
| `GET` | `/api/snapshots/<id>/diagnosis` | Получение готового заключения и списка угроз |
| `POST` | `/api/chat/stream/` | Потоковый SSE-чат с историей и Tool Calling |
| `GET` | `/api/snapshots/<id>/chat` | История переписки по снимку из БД |
| `DELETE`| `/api/snapshots/<id>/chat` | Очистка истории переписки по снимку |
| `GET` | `/api/snapshots/<id>/export-pdf` | Скачивание брендированного PDF-отчета |
| `GET` | `/api/snapshots/<id>/export-excel` | Скачивание подробного Excel-аудита |
| `GET` | `/api/templates` | Список готовых CSV-шаблонов |
| `POST` | `/api/templates/<id>/load` | Моментальная загрузка выбранного шаблона |
