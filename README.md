# AI Business X-Ray

**AI Business X-Ray** — сервис аналитической диагностики для малого и микробизнеса (ИП, розница, B2B-услуги, небольшие команды).

Сервис анализирует загруженные данные предпринимателя (выгрузки продаж, сделок, CRM в формате CSV) и формирует **диагноз**: где бизнес теряет деньги, почему это происходит, каков финансовый ущерб и какие конкретные шаги необходимо предпринять в первую очередь.

> **Главный принцип:**  
> AI не рассчитывает финансовые показатели и не выдумывает цифры — расчет метрик и поиск аномалий выполняет детерминированный код по жестким правилам. AI преобразует сухие факты и расчеты в понятный предпринимателю язык с доказательствами и рекомендациями.

## Ключевые компоненты

### 1. Бэкенд (`xray-be`)
Построен на **Django 5**.
- **Потоковый прокси-эндпоинт (`/api/chat/stream/`)**:
  - Реализует протокол **Server-Sent Events (SSE)** через `StreamingHttpResponse`.
  - В реальном времени транслирует ответ от внешнего OpenAI-совместимого API клиенту без буферизации (`Cache-Control: no-cache`, `X-Accel-Buffering: no`).
  - Позволяет фронтенду мгновенно печатать ответ по мере поступления токенов (как в ChatGPT / Claude).
- **Настройка CORS**: разрешены запросы с фронтенда (`django-cors-headers`).
- **Конфигурация**: берется из файла `xray-be/.env`:
  - `OPENAI_BASE_URL` — базовый адрес LLM API.
  - `OPENAI_API_KEY` — ключ доступа.

### 2. Генератор тестовых данных (`faker`)
Модуль для создания реалистичных CSV-выгрузок малого бизнеса (архетип *E-commerce / Розница*):
- **4 формата файлов**:
  - `canonical` — стандартные поля (`order_id`, `total_amount`, `order_date`, `status` и др.).
  - `moysklad` — стиль МойСклад / 1С (разделитель `;`, цены с запятой, даты `ДД.ММ.ГГГГ ЧЧ:ММ`).
  - `marketplace` — стиль выгрузок маркетплейсов (Wildberries / Ozon).
  - `messy` — неструктурированная «грязная» таблица («Чек», «Когда», «Скинули», перемешанные даты).
- **Инъекция бизнес-аномалий**:
  - `--anomaly-discounts` — утечка маржи через неконтролируемые скидки (20–50%).
  - `--anomaly-returns` — аномальный всплеск возвратов/отмен.

### 3. Демо-фронтенд (`xray-fe`)
Легковесная веб-страница без тяжелых зависимостей:
- Показывает, как фронтенд читает потоковый ответ через браузерный `ReadableStream` (`fetch`).
- Декодирует SSE-события `data: {...}` на лету и плавно выводит текст с анимированным курсором.

## Быстрый старт и запуск

### 1. Запуск бэкенда (Django)

```powershell
# Переход в папку бэкенда
cd xray-be

# Установка зависимостей (если запускается в новом окружении)
.\venv\Scripts\pip.exe install -r requirements.txt

# Запуск сервера разработки на порту 8000
.\venv\Scripts\python.exe xray_be\manage.py runserver 127.0.0.1:8000
```

Сервер будет доступен по адресу: `http://127.0.0.1:8000`  
Потоковый эндпоинт: `POST /api/chat/stream/` или `GET /api/chat/stream/?prompt=Ваш+запрос`

### 2. Запуск фронтенда (Stream Demo)

Любым статическим HTTP-сервером, например через Node.js:

```powershell
# Запуск из корня репозитория
npx --yes serve -l 3000 xray-fe
```

Откройте в браузере: **http://localhost:3000** и нажмите кнопку **«Hello world»**.

### 3. Генерация тестовых бизнес-данных

```powershell
# Запуск генератора (использует локальный .venv в папке faker)
.\faker\.venv\Scripts\python.exe faker/generate_ecommerce.py --count 300 --output-dir faker/data

# Генерация датасета с аномальными скидками для тестирования диагноза:
.\faker\.venv\Scripts\python.exe faker/generate_ecommerce.py --count 500 --anomaly-discounts --output-dir faker/data/problem_discounts
```

Сгенерированные файлы сохраняются в `faker/data/`.
