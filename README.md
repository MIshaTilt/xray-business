# AI Business X-Ray

**AI Business X-Ray** — интеллектуальный сервис бизнес-диагностики и финансового рентгена для малого и микробизнеса (E-commerce, услуги, B2B-продажи, розница).

Сервис анализирует загруженные таблицы продаж и CRM (CSV, Excel), находит скрытые финансовые утечки, рассчитывает точный ущерб в рублях и выдает практический пошаговый план действий с интерактивным AI-консультантом.

> **Фундаментальный принцип надежности:**  
> AI **не вычисляет финансовые показатели и не гадает на цифрах**. Расчет 7 бизнес-метрик, финансового ущерба (`money_impact`) и критичности угроз выполняется строгим детерминированным ядром по формулам. Нейросеть (`gemini-3.8-flash-high`) переписывает выводы живым деловым языком, отвечает на вопросы предпринимателя в потоковом чате с доступом к базе через **Tool Calling** и помогает сопоставлять нестандартные колонки через **AI-нормализатор**.

## Что умеет система

1. **Всеядный импорт данных:**
   - Чтение CSV (UTF-8, CP1251, автоопределение разделителей `;`, `,`, `\t`) и Excel (`.xlsx`, `.xls`).
   - Автоматический маппинг колонок по словарям синонимов и эвристикам типов данных.
   - **AI-нормализатор колонок (Smart Fallback)**: если колонки названы сленгом (*«Баблос»*, *«Кто тащит»*, *«Время залива»*), LLM анализирует примеры строк и сопоставляет поля без ручной настройки.
   - Меню готовых шаблонов (**«Шаблон ▼»**) прямо на главной странице.
2. **Аналитический движок 7 ключевых метрик (ТЗ §6):**
   - ⚡ `speed_to_lead` — скорость первого контакта с лидом.
   - ⏳ `stagnation` — зависшие сделки без движения с расчетом замороженной суммы в рублях.
   - 💸 `discount_leakage` — утечка маржи через скидки выше порога.
   - 🔄 `sales_cycle` — удлинение цикла сделки и задержка денег.
   - 🏢 `key_account_risk` — опасная концентрация выручки на 1–2 клиентах.
   - 💤 `dormant` — спящие клиенты без повторных покупок и касаний.
   - 📉 `funnel_dropoff` — провалы конверсии на этапах воронки.
3. **Полноценная база данных (Django ORM / SQLite / PostgreSQL):**
   - Модели `MaxUser`, `Upload`, `Snapshot`, `Deal`, `ChatMessage`.
   - Сохранение истории сканирований на главной странице.
   - Полное сохранение истории диалогов с AI по каждому снимку.
4. **Интерактивный AI-консультант с RAG и Tool Calling:**
   - Потоковая трансляция ответа (SSE) в реальном времени с поддержкой Markdown (заголовки, списки, акценты).
   - **Tool Calling (вызов инструментов к БД)**: нейросеть делает реальные SQL-запросы к сделкам снимка (`search_deals`, `get_manager_stats`, `get_top_clients`).
   - Интерактивные плашки вызова инструментов с просмотром параметров и результатов.
5. **Экспорт отчетов:**
   - **PDF-отчет**: фирменный документ с баллом здоровья воронки, суммой денег под угрозой, главным диагнозом и реестром сделок.
   - **Excel-аудит**: двухстраничная книга (`Резюме аудита` + `Зависшие сделки` с телефонами и менеджерами).

## Инструкция по запуску проекта

Для полноценной работы проекта требуются:
- **Python 3.10+** (виртуальное окружение уже создано в `xray-be/venv`);
- **Node.js 18+** и **npm**;
- Доступ к OpenAI-совместимому API (настроен в `xray-be/.env`).

---

### Шаг 1. Запуск бэкенда (Django API)

Откройте терминал (PowerShell или Bash) в папке проекта:

```powershell
# 1. Перейдите в каталог бэкенда
cd xray-be

# 2. Активируйте виртуальное окружение (Windows)
.\venv\Scripts\Activate.ps1
# Либо на Linux / macOS: source venv/bin/activate

# 3. Примените миграции базы данных (SQLite создастся автоматически)
python xray_be\manage.py migrate

# 4. Запустите сервер Django на порту 8000
python xray_be\manage.py runserver 127.0.0.1:8000
```

Сервер бэкенда доступен по адресу: **http://127.0.0.1:8000**  
Ключевые эндпоинты:
- `POST /api/uploads` — загрузка файла и смарт-маппинг
- `POST /api/snapshots` — запуск анализа и построение снимка
- `GET /api/snapshots` — список сохраненных сканов для главной страницы
- `POST /api/chat/stream/` — интерактивный SSE-чат с Tool Calling
- `GET /api/snapshots/<id>/export-pdf` — скачивание PDF-аудита
- `GET /api/snapshots/<id>/export-excel` — скачивание Excel-аудита
- `GET /api/templates` — список предустановленных шаблонов

---

### Шаг 2. Запуск фронтенда (React / Vite)

В **отдельном терминале** перейдите в каталог `xray-fe`:

```powershell
# 1. Перейдите в каталог фронтенда
cd xray-fe

# 2. Установите зависимости (если запускается впервые)
npm install

# 3. Режим разработки (Vite Dev Server)
npm run dev
```

Фронтенд запустится и будет доступен по адресу: **http://localhost:5173** (или **http://localhost:3000** при `npm run preview` / статическом сервере).

> **Примечание:** В файле `xray-fe/.env.local` установлен параметр `VITE_USE_FIXTURES=false`, благодаря чему фронтенд отправляет все запросы в реальный бэкенд Django.

## Сценарии тестирования

1. **Мгновенный старт через готовые шаблоны:**
   - Нажмите кнопку **«Шаблон ▼»** на главной странице.
   - Выберите любой файл, например:
     - *«Стандартный E-commerce»* — для полной проверки всех 7 метрик и чата.
     - *«🔥 Стресс-тест для AI-нормализатора»* — для демонстрации того, как нейросеть автоматически понимает сленговые заголовки (`Баблос`, `Кто тащит`, `Время залива`).
2. **Проверка экрана диагноза:**
   - Изучите карточки найденных проблем с точными суммами в рублях.
   - Нажмите **«📄 Скачать PDF»** или **«📊 Скачать Excel»** — скачается готовый аудит для инвестора или РОПа.
3. **Проверка AI-консультанта:**
   - Нажмите **«💬 Задать вопрос AI по отчету»**.
   - Спросите: *«Кто из менеджеров косячит в команде?»* или *«Назови топ-3 самые крупные сделки из отчета»*.
   - Обратите внимание на плашку **`⚙️ Запрос к базе... ▼`**: нажмите на нее, чтобы увидеть, как нейросеть через Tool Calling обратилась к базе данных сделок и выдала точный ответ без галлюцинаций.
