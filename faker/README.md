# Faker Test Data Generator for AI Business X-Ray

**Генератор синтетических бизнес-данных и моделирования аномалий воронки продаж**

> **Трек хакатона:** «Эффективный бизнес» (Минобрнауки России & Платформа MAX)  
> **Назначение:** Моделирование тестовых данных, воспроизводимая проверка аналитического ядра и тестирование AI-нормализатора (согласно п. 10 правил и разделу «Работа с данными», стр. 18)

---

## 1. Назначение и соответствие правилам работы с данными

В соответствии с методическими рекомендациями трека хакатона:
1. **Маркировка смоделированных данных (п. 10 правил):** Данные, создаваемые этим модулем, являются синтетическими (модельными) и служат для воспроизводимого тестирования работы системы без риска разглашения коммерческой тайны реальных предприятий.
2. **Проверка AI-нормализатора:** Генератор формирует различные форматы таблиц с типичными ошибками малого бизнеса (нестандартные заголовки, опечатки, смешанные форматы дат, сленг), позволяя проверить качество работы эвристического и LLM-маппинга колонок.
3. **Моделирование бизнес-патологий:** Скрипты позволяют инжектировать конкретные уязвимости (утечка маржи, зависшие сделки, удлинение цикла) с заданными параметрами для проверки точности расчета финансового ущерба (`money_impact`).

---

## 2. Поддерживаемые форматы и архетипы данных

Скрипт `generate_ecommerce.py` поддерживает генерацию 4 ключевых стилей выгрузок:

1. **`canonical` (Канонический формат):**
   - Англоязычные стандартные имена колонок (`deal_id`, `amount`, `order_date`, `status`, `manager`, `client`).
   - Используется как эталонный контрольный датасет для автоматического тестирования API.
2. **`moysklad` (Стиль 1С / МойСклад):**
   - Русскоязычные заголовки (*«Номер заказа»*, *«Дата документа»*, *«Контрагент»*, *«Сумма документа»*).
   - Разделитель точки с запятой (`;`), десятичные разделители с запятыми, форматы дат `ДД.ММ.ГГГГ ЧЧ:ММ`.
3. **`marketplace` (Стиль Wildberries / Ozon):**
   - Специфика интернет-торговли и маркетплейсов (*«ID отправления»*, *«К перечислению (Выручка)»*, *«Артикул»*, *«Статус доставки»*, *«Комиссия маркетплейса»*).
4. **`messy` (Реальная «грязная» таблица малого бизнеса):**
   - Нестандартные и сленговые названия колонок (*«Баблос»*, *«Кто тащит»*, *«Когда залили»*, *«Клиентос»*, *«Скинули, %»*).
   - Пропуски в данных и неконсистентные форматы телефонных номеров для проверки стрессоустойчивости AI-нормализатора.

---

## 3. Моделирование бизнес-аномалий (болезней воронки)

При генерации можно включать флаги патологий продаж:
- **`--anomaly-discounts` (Утечка маржи):** Инжектирует неоправданно высокие скидки менеджеров (от 20% до 50%) на крупных сделках, снижая итоговую маржинальность и активируя диагноз «Утечка маржи».
- **`--anomaly-returns` (Аномальный отвал):** Имитирует высокий процент отказов и срыва сделок на финальном этапе согласования договоров.
- **`--anomaly-stagnation` (Зависшие сделки):** Сдвигает даты создания заказов в прошлое, создавая пул сделок, застрявших на промежуточных этапах без движения более нормативного срока.

## 4. Быстрый старт и примеры использования

### Активация окружения:
```powershell
# Windows PowerShell
.\faker\.venv\Scripts\Activate.ps1

# Linux / macOS
source faker/.venv/bin/activate
```

*(Или запуск напрямую через интерпретатор окружения `.\faker\.venv\Scripts\python.exe`).*

### Примеры команд генерации:

```powershell
# 1. Сгенерировать все 4 формата по 200 строк в папку templates/:
python faker/generate_ecommerce.py --count 200 --output-dir templates/

# 2. Сгенерировать датасет с аномальными скидками для проверки расчета ущерба:
python faker/generate_ecommerce.py --count 300 --anomaly-discounts --output-dir faker/data/problem_discounts

# 3. Сгенерировать эталонный канонический датасет для нагрузочного тестирования (1000 строк):
python faker/generate_ecommerce.py --format canonical --count 1000 --output-dir faker/data/benchmark
```

## 5. Использование в проверке решения

Сгенерированные файлы можно:
1. Загружать вручную в веб-интерфейс [http://localhost:5173](http://localhost:5173) через форму Drag & Drop;
2. Помещать в каталог `templates/` для автоматического появления в выпадающем меню **«Шаблон ▼»** внутри Mini App в мессенджере MAX;
3. Использовать в скриптах нагрузочного тестирования бэкенда (`scripts/test_api_suite.py`).
