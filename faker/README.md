# Faker Test Data Generator for AI Business X-Ray

В этой папке находятся скрипты для генерации синтетических («фейковых») бизнес-данных под архетипы проекта (согласно `idea/xray1.md` и `idea/xray2.md`).

Эти данные создаются для тестирования:
1. **Смарт-маппинга колонок (AI / heuristic normalizer)**: распознавание названий полей, синонимов, разделителей и форматов дат.
2. **Аналитического движка X-Ray**: подсчет метрик (скорость ответа, скидки, LTV, конверсии, средний чек).
3. **Правил выявления проблем (Диагностики)**: утечка маржи через скидки, аномальные возвраты, зависшие заказы.

---

## 1. Активация окружения

В папке `faker` уже развернуто локальное виртуальное окружение `.venv` с установленной библиотекой `Faker`.

```powershell
# Активация окружения на Windows PowerShell:
.\faker\.venv\Scripts\Activate.ps1

# Либо запуск напрямую через интерпретатор окружения:
.\faker\.venv\Scripts\python.exe faker/generate_ecommerce.py
```

## 2. Генерация данных для «E-commerce / Розница»

Скрипт: `generate_ecommerce.py`

### Возможности генератора:
- Генерирует заказы розничного магазина / маркетплейсов с реалистичными товарами, ценами, клиентами, каналами продаж (Сайт, Ozon, WB, Авито, оффлайн) и метриками скорости реакции.
- Поддерживает 4 формата выгрузки для проверки устойчивости смарт-маппинга:
  - `canonical`: стандартные имена полей на английском (`order_id`, `total_amount`, `order_date`, `status`, ...);
  - `moysklad`: выгрузка в стиле МойСклад / 1С (заголовки на русском, разделитель `;`, цены с запятой, даты `ДД.ММ.ГГГГ ЧЧ:ММ`);
  - `marketplace`: выгрузка в стиле Wildberries / Ozon (`ID отправления`, `К перечислению (Выручка)`, `Артикул`, ...);
  - `messy`: «грязная» таблица малого бизнеса (нестандартные имена колонок «Чек», «Когда», «Кто купил», «Скинули», перемешанные форматы дат и пропуски).
- Поддерживает флаги инъекции аномалий (болезней бизнеса):
  - `--anomaly-discounts` (утечка маржи: неоправданно высокие скидки 20-50%);
  - `--anomaly-returns` (аномальный всплеск возвратов/отмен).

### Примеры запуска:

```powershell
# Сгенерировать все 4 формата по 300 строк в папку faker/data:
.\faker\.venv\Scripts\python.exe faker/generate_ecommerce.py --count 300 --output-dir faker/data

# Сгенерировать датасет с аномальными скидками для тестирования диагноза "Утечка маржи":
.\faker\.venv\Scripts\python.exe faker/generate_ecommerce.py --count 500 --anomaly-discounts --output-dir faker/data/problem_discounts

# Сгенерировать только канонический файл:
.\faker\.venv\Scripts\python.exe faker/generate_ecommerce.py --format canonical --count 100 --output-dir faker/data
```
