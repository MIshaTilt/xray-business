# MAX Chatbot Module for X-Ray Business

Официальный модуль чат-бота для мессенджера **MAX**, разработанный на базе библиотеки `@maxhub/max-bot-api`.

## 📌 Возможности модуля
1. **Обработка события «Старт» (`bot_started`)**:
   - При нажатии пользователем кнопки «Старт» в мессенджере отправляет приветственное сообщение с описанием X-Ray Business.
   - Прикрепляет инлайн-кнопки:
     - `open_app`: открывает Mini App во встроенном WebView MAX.
     - `link`: универсальная ссылка `https://max.ru/<bot_username>?startapp`.
     - `link`: ссылка на веб-версию.
2. **Обработка текстовой команды `/start`**:
   - Отправляет то же приветственное сообщение и кнопки.
3. **Обработка команды `/help`**:
   - Выводит краткую справку по функционалу сервиса (экспресс-аудит, воронка, CRM-интеграции).
4. **Обработка произвольных текстовых сообщений**:
   - Вежливо подсказывает пользователю, что весь функционал доступен в Mini App, и прикрепляет кнопку перехода.
5. **Автоматическая регистрация команд бота**:
   - Регистрирует команды `/start` и `/help` в меню мессенджера MAX через API.
6. **Поддержка режимов работы**:
   - **Long Polling** (по умолчанию для локальной разработки и тестирования).
   - **Webhook** (для production-серверов).

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
npm install
```

### 2. Переменные окружения (.env)
Модуль автоматически считывает переменные окружения из `.env` или `xray-be/.env`:
```env
MAX_BOT_TOKEN=f9LHodD0cOJBhxITwPCdJEVxZ7O2jzj6oDVpd_ODgTheRYaSUX8ErQbLWGisLOw5-U9xswXPu-vQfO0yAcCT
MAX_BOT_USERNAME=se14421867_bot
MAX_APP_URL=https://xray-business-bot.online
```

### 3. Запуск
```bash
# Из папки max-bot:
npm start

# Или из корня проекта:
npm run bot
```

## 🛠 Архитектура файлов
- `config.js` — загрузка настроек и конфигурация TLS.
- `bot.js` — инициализация бота, сценарии и шаблоны сообщений.
- `index.js` — точка входа, проверка токена, регистрация команд и запуск.
