## 1. Назначение и соответствие регламенту платформы MAX

Модуль чат-бота выступает центральной входной точкой пользователя в экосистему сервиса внутри мессенджера MAX в полном соответствии с регламентом хакатона:

1. **Связка с Мини-приложением (п. 5 правил):** Мини-приложение подключено к чат-боту и не изолировано от него. Бот формирует нативные инлайн-кнопки типа `open_app`, открывающие Mini App во встроенном WebView мессенджера.
2. **Фиксация имени бота (п. 11 правил):** В соответствии с архитектурным ограничением платформы MAX имя бота зафиксировано как `@se14421867_bot` и сохраняется неизменным.
3. **Безопасность токенов (п. 8 правил):** Рабочие токены и секреты не публикуются в открытом репозитории. Конфигурация подгружается из переменных окружения (`.env`), а актуальный ключ для экспертной проверки жюри передается на **1-м служебном слайде презентации**.

## 2. Сценарии работы чат-бота

```
                             [ Пользователь в MAX ]
                                       │
                 ┌─────────────────────┴─────────────────────┐
                 │                                           │
         Событие bot_started                           Команда /start
                 │                                           │
                 └─────────────────────┬─────────────────────┘
                                       ▼
                       Приветственное сообщение бота
                                       │
            ┌──────────────────────────┴─────────────────────┐
            ▼                                                ▼
     Кнопка «open_app»                               Кнопка «Веб-версия»
   (Встроенный WebView MAX)                      (xray-business-bot.online)
```

1. **Обработка события «Старт» (`bot_started`):**
   - Срабатывает в момент, когда пользователь впервые нажимает кнопку «Старт» в профиле бота в мобильном или десктопном клиенте MAX.
   - Бот отправляет емкое визуальное приветствие с перечислением ключевых возможностей X-Ray (экспресс-рентген, аудит зависших сделок, AI-консультант с Tool Calling).
2. **Обработка команды `/start`:**
   - Отправляет приветственный дашборд с набором инлайн-кнопок:
     - `open_app`: открывает мини-приложение прямо внутри мессенджера MAX через защищенный HTTPS-фрейм;
     - `link` (Веб-версия): ссылка на внешний браузерный интерфейс.
3. **Обработка команды `/help`:**
   - Предоставляет пошаговую инструкцию по прохождению аудита воронки продаж и работе с AI-консультантом.
4. **Обработка произвольных текстовых сообщений:**
   - Если пользователь пишет произвольный текст в чат, бот распознает намерение и предлагает запустить Mini App для проведения полноценного аудита с прикрепленной кнопкой быстрого перехода.
5. **Автоматическая регистрация команд в меню MAX:**
   - При старте бот регистрирует команды `/start` и `/help` через API MAX, чтобы они отображались в системной кнопке меню мессенджера.

## 3. Быстрый старт и запуск

### 3.1. Установка зависимостей
```bash
cd max-bot
npm install
```

### 3.2. Настройка переменных окружения
Создайте или отредактируйте файл `.env` в корне репозитория (или в папке `max-bot`):
```env
MAX_BOT_TOKEN=your_max_bot_token_from_presentation_slide_1
MAX_BOT_USERNAME=se14421867_bot
MAX_APP_URL=https://xray-business-bot.online
```

### 3.3. Варианты запуска

#### Вариант А: Официальный Node.js модуль (@maxhub/max-bot-api)
```bash
# Из папки max-bot:
npm start

# Или из корня репозитория:
npm run bot
```

#### Вариант Б: Python-реализация бота (Long Polling)
Для сред, где предпочтителен запуск на Python:
```bash
python scripts/max_bot.py
```

#### Вариант В: Команда Django Management
```bash
python xray-be/xray_be/manage.py run_max_bot
```

#### Вариант Г: Production Webhook
Бэкенд предоставляет готовый вебхук для платформы MAX:
- URL приема событий: `POST https://xray-business-bot.online/api/max/webhook`
- Проверка доступности: `GET https://xray-business-bot.online/api/max/webhook`

## 4. Архитектура файлов модуля

- **`config.js`** — Загрузка параметров окружения, валидация конфигурации и настройка TLS.
- **`bot.js`** — Логика сценариев, шаблоны интерактивных клавиатур (`open_app`, `link`), регистрация команд.
- **`index.js`** — Точка входа: проверка токена бота, подписка на входящие события и запуск поллинга.
