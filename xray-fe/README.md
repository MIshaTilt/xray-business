# X-Ray — Мини-приложение (Frontend)

Фронтенд сервиса аналитической диагностики продаж для малого бизнеса.  
Построен на **React**, **TypeScript**, сборщике **Vite** и дизайн-системе **@maxhub/max-ui** (для нативной интеграции в экосистему MAX).

---

## Архитектура экранов (Screens)

1. **`Home.tsx`** — Главный экран:
   - Drag & Drop и выбор пользовательских файлов (CSV, XLSX, XLS).
   - Выпадающее меню **«Шаблон ▼»** для быстрого тестирования типовых датасетов (E-commerce, 1С, Wildberries, сленговые CRM).
   - Список **«История сканов»**: подтягивает сохраненные отчеты из базы данных бэкенда, показывает статус, дату и финансовый вердикт.
2. **`Mapping.tsx`** — Подтверждение колонок:
   - Автоматически выставляет соответствие колонок из файла канонической схеме X-Ray.
   - Показывает готовность 7 метрик в реальном времени.
3. **`Processing.tsx`** — Экран ожидания расчета:
   - Анимированный рентген воронки и опрос готовности снимка через API.
4. **`Diagnosis.tsx`** — Экран заключения:
   - Главный вердикт и сумма потерь.
   - Карточки критических угроз с рекомендациями.
   - Кнопки **«📄 Скачать PDF»** и **«📊 Скачать Excel»** для выгрузки отчетов.
   - Кнопка перехода в **«💬 Задать вопрос AI по отчету»**.
5. **`ChatScreen.tsx`** — Интерактивный AI-консультант:
   - Потоковая трансляция ответа (SSE) с печатью в реальном времени.
   - Парсинг Markdown (`marked`): заголовки, списки, выделения.
   - **Визуализация Tool Calling (`ToolCallBadge.tsx`)**: раскрывающиеся плашки с параметрами SQL-запросов и данными из базы.
   - Синхронизация истории диалогов с базой данных Django ORM.
6. **`MetricDetail.tsx`** — Детальный разбор выбранной метрики с доказательствами и формулами.
7. **`MissingData.tsx`** — Подсказки, каких колонок не хватило для расчета остальных метрик.

## Запуск в разработке

```bash
# Установка пакетов
npm install

# Запуск dev-сервера с hot-reload
npm run dev
```

По умолчанию dev-сервер запускается на `http://localhost:5173`.  
Все запросы `/api/*` автоматически проксируются на бэкенд `http://127.0.0.1:8000`.

---

## Сборка для продакшна

```bash
npm run build
```

Собранные статические файлы будут сохранены в папке `dist/`.  
Для предварительного просмотра продакшн-сборки:

```bash
npm run preview
```

---

## Переменные окружения (`.env.local`)

- `VITE_USE_FIXTURES=false` — переключает фронтенд с локальных мок-фикстур на реальный бэкенд Django.
- `VITE_API_URL=http://127.0.0.1:8000` — базовый URL бэкенда.
- `VITE_DEBUG_USER=12345` — идентификатор пользователя для тестирования вне контейнера MAX.
