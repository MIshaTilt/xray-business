# X-Ray — мини-приложение

Фронтенд сценария: Home, маппинг, ожидание, диагноз, сделки, недостающие колонки.

Пока бэкенда нет, приложение отвечает локальными фикстурами. Токен бота сюда не кладётся.

```bash
npm install
npm run dev
```

Проверка домена:

```bash
npm test
```

Чтобы ходить в Django, в `.env` поставьте `VITE_USE_FIXTURES=false`. Запросы идут на `/api` и в dev проксируются на `http://127.0.0.1:8000`. В браузере вне MAX бэкенд в режиме хакатона принимает `X-Debug-Token` и `X-Debug-User` из `VITE_DEBUG_TOKEN` и `VITE_DEBUG_USER`. Эти заголовки уходят только из dev-сборки.
